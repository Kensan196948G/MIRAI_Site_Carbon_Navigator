## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| 名称 | MIRAI Site Carbon Navigator |
| 目的 | 建設現場の CO2 排出量を月次算定し、削減施策・報告・発注者提案へ接続する |
| 利用者 | 現場（約600名従業員）、本社・IT/DX 7名、経営層、協力会社・発注者 |

| 技術 | FastAPI / SQLAlchemy / PostgreSQL 16（Docker Compose）/ Bootstrap 5 / Cloudflare Tunnel / GitHub Actions |

11. 同工種ベンチマーク・削減シナリオ・翌月予測
12. TOTP 2FA と Entra ID 等 OIDC 対応
