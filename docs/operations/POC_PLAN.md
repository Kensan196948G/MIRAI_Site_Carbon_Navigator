# Phase 8: 2現場実地PoC計画書（2026-09-01 開始予定）

## 1. 目的

- 実際の現場データで「入力 → 承認 → 算定 → レポート → 削減アクション」の一連の業務フローが成立することの実証
- 現場担当（約600名組織の代表 2 現場）、IT/DX 7 名、環境担当、経営層、発注者（client ポータル）の利用受入確認
- 本番運用開始判定（Phase 0〜1 完了）のための受入基準を満たすこと

## 3. PoC データ範囲

- 燃料（軽油・ガソリン・A重油）、建機稼働、船舶、材料（鋼材・コンクリート・アスファルト）、輸送、電力、廃棄物
- 対象期間: 2026-09 月分を日次入力、8〜9月分の実績データで算定検証
- 排出係数: 現行マスタ + 環境省公表値との突合結果を適用（突合は PoC 開始前までに完了）

### 入力データの定義

| 区分 | 入力項目 | 単位 | 入手先 | 異常系チェック |
|---|---|---|---|---|
| 燃料 | 軽油・ガソリン・A重油・LPG | L / kg | 燃料納入伝票・給油記録 | 月間使用量が前月比±100%超で警告 |
| 建機 | 油圧ショベル・クレーン等 | 稼働時間 h | 日報・テレマティクス | 月間稼働時間がカレンダー時間を超過しないか |
| 材料 | 鋼材・コンクリート・セメント等 | t | 納品書・出来高 | 数量ゼロ/マイナス/単位誤り |
| 輸送 | トラック・船舶 | t-km | 運送依頼書 | 重量×距離の整合 |
| 電力 | 現場電力 | kWh | 電力会社請求書 | 契約電力との整合 |
| 廃棄物 | 建設廃棄物 | t | マニフェスト | 運搬先・重量の整合 |

## 4. スケジュール（30日間）

| 週 | 内容 | 完了条件 |
|---|---|---|
| 第1週 | 準備・利用者教育（30分×2回）、現場別アカウント設定、client 割当 | 全参加者がログイン・操作研修完了 |
| 第2週 | 実データ入力（9月分）・支店承認・環境部承認・月次締め | 2現場とも承認済み活動量 100% |

| 第4週 | 削減アクション登録・SBTi/クレジット確認、受入評価・報告 | 受入基準 100% 達成、課題リスト整理 |

## 5. 受入基準（完了条件）

1. 主要フロー（入力→承認→算定→レポート）がエラーなく完了（異常系含む）
2. 算定値と現場帳票・伝票の突合誤差 0%（単位換算含む）
3. RBAC（site 自支店 / client 割当のみ）の実操作確認
4. 監査ログ・変更履歴・締め後の書換拒否の確認
5. バックアップ取得・復元試験（本番相当）が成功
6. 公開 URL・監視・通知（SMTP/Teams 設定後）が動作
7. 利用者アンケート（使いやすさ・業務時間削減）平均 4/5 以上
8. 残課題がすべて「受容済み」または「計画済み」となる

### 受入証跡

- 各週の操作ログ・監査ログ・エクスポートファイルを `docs/operations/` 配下へ保存
- 完了時は `docs/evaluation/TEST_EVIDENCE.md` へ PoC 結果（合格/不合格・課題）を追記

## 6. データ品質・係数確認（PoC 前必須）

- 環境省「算定・報告・公表制度」の排出係数一覧と突合（燃料・電力・輸送）
- 電気事業者別排出係数（TEPCO 2024年度 0.421 等）の年度更新日管理
- 建機・船舶・材料の原単位は出典（メーカーカタログ・業界資料）を明記
- 取込 Excel の入力チェック（必須項目・単位・重複・月形式）の実運用確認

## 7. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 現場担当の入力負荷 | 高 | Excel 取込・前月コピー・督促機能の活用、1日15分以内を目標 |
| 係数誤りによる数値不信 | 高 | 一次情報との突合、出典・更新日表示、変更履歴 |
| 通知未設定による督促漏れ | 中 | SMTP/Teams 設定を PoC 開始までに完了 |
| 同時アクセス性能 | 低 | 2現場×数名なので低負荷、負荷試験は本番化前 |
| 発注者への誤表示 | 高 | client 権限テストを毎週実行 |
| 現場選定・参加者調整の遅延 | 中 | 9/1 開始 2 週間前までに仮決定、1 週間前までに確定 |
| データ入手先（伝票等）の電子化不足 | 中 | Excel 取込・写真/OCR 代替も準備 |
| 通知チャネル未設定のまま開始 | 高 | PoC 開始前の設定・試験を完了条件化 |
