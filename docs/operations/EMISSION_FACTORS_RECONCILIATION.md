# 排出係数 一次情報突合台帳

最終更新: 2026-08-12 / 対象: PoC（2026-09-01 開始）前の排出係数マスタ

## 1. 目的と方法

PoC 開始前に、排出係数マスタの値を国・自治体・業界団体等の一次情報と突合し、
「出典・更新日・適用開始日」を台帳化する。算定結果には適用時の係数・出典・適用
開始日がスナップショット保存されるため、後から係数を改訂しても過去レポートの
根拠は追跡できる。

突合には以下の公式資料を使用した。

## 3. 反映方法

1. バックアップ取得: `./scripts/backup.sh`
2. 変更確認: `python scripts/reconcile_emission_factors.py`
3. 適用: `python scripts/reconcile_emission_factors.py --apply`
4. 確認: 係数一覧 API または DB で、2026-08-12 適用開始の新バージョンが存在することを確認

適用後は、対象月が 2026-08 以降の算定で新係数が使われる。過去月の算定結果は
スナップショットのため影響しない。

## 4. 残課題

- メニュー別契約（東京電力EP 0.452 / 関西電力 0.415 等）が判明したらメニュー別（残差）係数へ切替え
- 建機・船舶・廃棄物・水道の現場実績値（サプライヤー提示・仕様書）による更新
- 報告先（公共工事・特定排出者報告・SBTi）に応じた係数体系切替機能の設計
