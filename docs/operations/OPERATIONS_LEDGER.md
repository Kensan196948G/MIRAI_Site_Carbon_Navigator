## 記録様式

```text
YYYY-MM-DD HH:MM 項目名 / 担当 / 結果（OK・NG・保留） / 備考 / 次回予定
```

## 初回実施記録（本番デプロイ日）

- ヘルス監視: 設定済み（cron 5分毎、`logs/monitor.log`）
- バックアップ: 設定済み（cron 毎日 02:00、14世代保持）
- 通知試験: チャネル未設定のため「未設定」、SMTP/Teams導入後に再試験
- 復元試験: 本番デプロイ時に実施（詳細は最終報告に記録）
